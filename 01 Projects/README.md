# 01 Projects

> [!info] Proyecto = evidencia
> Un proyecto demuestra que conectas conocimientos y tomas decisiones. Usa [[Templates/Project]] y enlaza cada habilidad, laboratorio y fuente.

## Antes de empezar

- [ ] Problema y usuario definidos
- [ ] Resultado medible
- [ ] Alcance y limites escritos
- [ ] Dependencias enlazadas

## Al terminar

- [ ] README reproducible
- [ ] Tests y manejo de errores
- [ ] Logs y diagnostico
- [ ] Seguridad, backup y rollback cuando aplique
- [ ] Retrospectiva y siguiente mejora
