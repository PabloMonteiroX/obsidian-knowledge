# 03 Resources

> [!info] Recursos = referencias, no vertedero
> Conserva documentacion, libros y cursos por su utilidad futura. Procesa cada recurso con [[Templates/Source]] y enlaza las notas que realmente produzca.

## Criterio de conservacion

- [ ] Tiene autor, version o fecha
- [ ] Responde una pregunta concreta
- [ ] Tiene notas derivadas enlazadas
- [ ] Se conoce su limite o contexto

Si no pasa estos criterios, dejalo en Inbox hasta procesarlo o archivarlo.
