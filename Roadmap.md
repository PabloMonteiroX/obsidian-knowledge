# Roadmap Senior

> [!info] Como usar el roadmap
> Avanza por dependencias, no por entusiasmo. Para cada bloque crea una nota de concepto, un procedimiento, un laboratorio y una evidencia. Marca la fase solo cuando puedas recuperar, ejecutar y diagnosticar.

## Fase 1 — Fundamentos

- [ ] C: tipos, funciones, memoria, punteros y estructuras
- [ ] Git, Bash, compilacion y debugging
- [ ] Algoritmos, estructuras de datos y testing

## Fase 2 — Linux profesional

- [ ] Procesos, permisos, almacenamiento y systemd
- [ ] Redes Linux, SSH, logs y troubleshooting
- [ ] Scripting y seguridad basica

## Fase 3 — Desarrollo aplicado

- [ ] Python para automatizacion y tooling
- [ ] SQL: modelado, transacciones, indices y tuning
- [ ] Java: JVM, concurrencia, APIs y arquitectura

## Fase 4 — Redes

- [ ] TCP/IP, subnetting, switching y routing
- [ ] VLAN, OSPF, ACL, NAT, DHCP y DNS
- [ ] Laboratorios CCNA y troubleshooting

## Fase 5 — Certificaciones

- [ ] LPIC: administracion Linux amplia
- [ ] RHCSA: operacion practica en Red Hat
- [ ] CCNA: configuracion y diagnostico de redes Cisco

## Regla de avance

Un tema pasa a `practiced` solo despues de resolver un laboratorio o proyecto reproducible y documentar un fallo real.

## Ciclo semanal

- [ ] Elegir un solo resultado medible
- [ ] Revisar prerrequisitos
- [ ] Estudiar una fuente primaria
- [ ] Crear el ejemplo minimo
- [ ] Ejecutar un laboratorio sin copiar
- [ ] Registrar error, causa y verificacion
- [ ] Enlazar notas y programar revision

## Dependencias del recorrido

```text
C + Git + Bash
	↓
Linux + procesos + redes
	↓
Python + SQL + Java
	↓
Sysadmin + CCNA
	↓
LPIC + RHCSA + proyectos integradores
```

La flecha indica una dependencia recomendada, no una prohibicion: puedes explorar otros temas, pero vuelve al prerrequisito cuando la practica se bloquee.
