# LPIC — MOC

> [!info] Como trabajar este MOC
> Convierte cada objetivo en una pregunta, un comando verificable y un laboratorio. El examen se prepara practicando tareas, no solo reconociendo respuestas.

> [!example] Ejemplo minimo
> Para permisos: crea un usuario y un archivo de prueba, predice el acceso, cambia permisos, verifica con `ls -l` e intenta el acceso con el usuario correcto.
