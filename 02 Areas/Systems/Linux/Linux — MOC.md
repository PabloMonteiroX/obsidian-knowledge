# Linux — MOC

> [!info] Como trabajar este MOC
> Aprende Linux por sintomas y capas: proceso, permisos, almacenamiento, red y servicio. Para cada practica registra comando, salida esperada, fallo introducido y recuperacion.

> [!example] Ejemplo minimo
> Para un servicio: consulta su estado, revisa logs, cambia una configuracion segura, reinicia, verifica y documenta rollback.
