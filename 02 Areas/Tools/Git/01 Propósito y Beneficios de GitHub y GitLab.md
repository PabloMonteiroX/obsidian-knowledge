GitHub y GitLab son proveedores de control de versiones basados en la nube que almacenan proyectos en repositorios y facilitan la colaboración en equipos de desarrollo.

**Detalles Clave:**

- Permiten publicar proyectos como "open-source" (código visible para todos) o "closed-source" (acceso restringido a personas autorizadas)
- Facilitan la revisión de código: los compañeros suben cambios directamente, y otros pueden comentar en archivos o líneas específicas, e incluso proponer ediciones sugeridas desde el navegador
- Permiten fusionar cambios aprobados en la rama principal para que todo el equipo acceda al código actualizado
- Incluyen rastreadores de incidencias para asignar tickets, aceptar reportes de errores del público y planificar sprints mediante tableros de proyectos

**Por Qué Importa:** Estas plataformas eliminan la necesidad de compartir código por Discord o llamadas de pantalla compartida, centralizando la colaboración, la revisión y la gestión de tareas en un solo lugar.
