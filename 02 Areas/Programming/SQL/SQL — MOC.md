# SQL — MOC

> [!info] Como trabajar este MOC
> No memorices consultas aisladas. Parte de un modelo, predice el resultado, ejecuta, inspecciona el plan y mide el efecto de cada indice o transaccion.

> [!example] Ejemplo minimo
> Para un JOIN: dibuja las tablas, define la cardinalidad esperada, ejecuta con datos pequenos y comprueba que el plan coincide con tu hipotesis.
