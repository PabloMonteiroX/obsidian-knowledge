# Networking — MOC

> [!info] Como trabajar este MOC
> Predice el camino de un paquete antes de usar comandos. Dibuja capas, direcciones, rutas y fronteras de confianza; despues verifica con capturas y tablas.

> [!example] Ejemplo minimo
> Para DNS: formula la consulta, identifica el resolver, observa la respuesta y explica que cambiaria con cache, timeout o fallo de autoridad.
