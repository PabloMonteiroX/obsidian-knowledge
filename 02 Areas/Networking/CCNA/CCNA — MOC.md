# CCNA — MOC

> [!info] Como trabajar este MOC
> Cada objetivo del examen debe terminar en una topologia reproducible. Configura, verifica, introduce un fallo y diagnostica sin mirar la solucion.

> [!example] Ejemplo minimo
> Para VLANs: crea dos VLAN, configura un trunk, verifica la tabla y explica por que un host de una VLAN no llega a otra sin routing.

- Network fundamentals
- Network access
- IP connectivity
- IP services
- Security fundamentals
- Automation and programmability
